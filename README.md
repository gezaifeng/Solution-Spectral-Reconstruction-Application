# 多色块编码溶液光谱智能重建软件 V1.0

## 运行

```bash
pip install -r requirements.txt
python main.py
```

## V1.0 功能

- 支持 JPG / JPEG / PNG / BMP / TIFF 图像导入。
- 支持单张导入和批量导入。
- 手动框选上方 Ref 与下方 Sample 两个矩形区域。
- 支持设置色卡行列数、中心采样面积、每块采样点数、黑边内缩比例。
- 默认使用 log_ratio 特征：sRGB linearization → log(sample) - log(ref) → clip[-8,8] → per-image channel z-score。
- 使用 ResCNN + best.pth 输出 190 维吸光度光谱。
- 自动保存 ref_rgb.npy、sample_rgb.npy、features_log_ratio.npy、spectrum.npy、spectrum.csv、spectrum.xlsx、spectrum.png 和 task_record.json。

## 操作流程

1. 进入“重建”页面。
2. 导入单张或批量导入图片。
3. 选择当前图片。
4. 点击“框选 Ref”，在图像中框选上方参考色卡。
5. 点击“框选 Sample”，框选下方样本色卡。
6. 根据黑边情况调整“黑边内缩-横向/纵向”。
7. 点击“预测当前图像”。
8. 在下方大图区域查看光谱曲线，或点击“打开当前结果目录”查看导出文件。

## V1.1 更新说明

本版本新增：

1. 自动识别 Ref / Sample 区域
   - 在“重建”页面点击“自动识别当前图像”；
   - 识别成功后会自动显示蓝色 Ref 框和绿色 Sample 框；
   - 如果识别不准确，可以继续点击“手动框选 Ref / Sample”覆盖自动结果。

2. 批量自动识别并预测
   - 批量导入图像后，点击“批量自动识别并预测”；
   - 适合拍摄结构一致、色卡边框清晰的实验图像；
   - 失败的图像可以后续手动框选后单独预测。

3. 历史识别与结果管理
   - 左侧新增“历史”页面；
   - 每次预测都会保存输入图像副本、中间特征、预测光谱、CSV/XLSX/NPY/PNG 和 task_record.json；
   - 历史页支持刷新记录、打开结果目录、打开光谱图、载入历史图像到重建工作台。

4. 依赖更新
   - 自动识别模块需要 opencv-python。
   - 请重新执行：

```bash
pip install -r requirements.txt
```

## V1.2 交互优化说明

本版本针对界面交互进行了优化：

- 首页改为居中布局，功能卡片只保留图标和功能文字。
- 首页右侧参数变为可点击按钮，可跳转到相关页面查看或调整。
- 重建工作台右侧参数栏加宽，便于查看和调整提取参数。
- 自动识别成功后不再弹出确认窗口，用户可直接在图像中检查识别区域；不准确时可用手动框选覆盖。
- Ref/Sample 框选区域改为低透明填充 + 深色边框，便于观察图像内容。
- 光谱标题改为“样本名-重构光谱”，并设置中文字体优先级，减少中文乱码。
- 历史页面同时展示原图识别区域和重构光谱，便于事后复查。
